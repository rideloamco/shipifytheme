# Loam Co. Website UI Kit

Recreation of the Loam Co. Shopify storefront homepage targeting the **Ride** theme.

## What's here
- `index.html` — full interactive homepage (working cart, drawer, newsletter sign-up)
- `Components.jsx` — all components: NavBar, Hero, Marquee, StatStrip, CategoryGrid, ProductCard/Grid, Manifesto, WhyRiders, Journal, Reviews, NewsletterCTA, FinalCTA, Footer, CartDrawer

## SEO structure baked in
- H1: "Ride hard. Stay comfortable. Look good."
- H2 sections: Shop by Category · Built for the graft · Born on the trails · Why riders choose Loam Co. · Trail notes · From the dirt cult · Join the dirt cult · Ready to ride in comfort
- Title tag and meta description match the brief
- Internal links to category pages (placeholder hrefs)

## Notes for Shopify "Ride" theme mapping
The Ride theme is section-based and type-forward. Each component here maps cleanly to a Ride section:
- `Hero` → image-with-text section
- `StatStrip` → multi-column section
- `CategoryGrid` → collection-list section
- `ProductGrid` → featured-collection section
- `Marquee` → announcement bar / marquee section
- `Manifesto`, `WhyRiders` → image-with-text / multi-column
- `Journal` → blog-posts section
- `Reviews` → testimonials section
- `NewsletterCTA` → newsletter section

## Image placeholders
Hero, category, product, and journal images are intentionally rendered as labelled black placeholders ("ATTACH PHOTOGRAPHY"). Per brand rules, do **not** invent imagery — request real action photography from the founder.
